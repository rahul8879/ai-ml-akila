# Module 4: Machine Learning

## Overview
This module covers fundamental machine learning algorithms, from supervised to unsupervised learning.

## Prerequisites
- Module 1: Python Fundamentals
- Module 2: Mathematics (Linear Algebra & Statistics)
- Module 3: Data Analysis

## Learning Objectives
By the end of this module, you will be able to:
- Understand and implement classification algorithms
- Build regression models for prediction
- Evaluate model performance using various metrics
- Apply tree-based methods and ensemble learning
- Perform clustering for unsupervised learning
- Select appropriate algorithms for different problems

## Study Order

### Supervised Learning - Classification
1. **theory/01_knn.ipynb** - K-Nearest Neighbors algorithm
2. **theory/02_performance.ipynb** - Model evaluation metrics
3. **theory/03_logistics_regression.ipynb** - Logistic regression for classification
4. **theory/08_Naive_bayes.ipynb** - Probabilistic classification

### Supervised Learning - Regression
5. **theory/04_linear_regression.ipynb** - Linear regression fundamentals

### Tree-Based Methods
6. **theory/05_Decision_tree.ipynb** - Decision tree algorithm
7. **theory/06_Random_forest.ipynb** - Random forest ensemble method
8. **theory/07_boosting.ipynb** - Gradient boosting techniques

### Unsupervised Learning
9. **theory/09_clustering_algorithm.ipynb** - K-means and hierarchical clustering

## Key Concepts to Master
- Train/test split and cross-validation
- Overfitting vs underfitting
- Bias-variance tradeoff
- Feature scaling and normalization
- Hyperparameter tuning
- Performance metrics (accuracy, precision, recall, F1, RMSE, R²)
