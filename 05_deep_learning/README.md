# Module 5: Deep Learning

## Overview
This module introduces neural networks and deep learning frameworks, with a focus on PyTorch.

## Prerequisites
- Module 4: Machine Learning (solid understanding required)
- Module 2: Mathematics (linear algebra especially important)
- Module 1: Python Fundamentals (NumPy proficiency)

## Learning Objectives
By the end of this module, you will be able to:
- Understand neural network architecture and training
- Work with tensors and automatic differentiation
- Build and train models using PyTorch
- Apply deep learning to NLP tasks
- Implement common architectures (CNNs, RNNs, Transformers)

## Study Order

### Fundamentals
1. **fundamentals/01_tensor.ipynb** - Introduction to tensors
2. **fundamentals/02_vector_operation.ipynb** - Vector and matrix operations
3. **fundamentals/DL-II.pdf** - Deep learning theory reference

### PyTorch Framework
4. **pytorch/** - PyTorch tutorials and examples

### Natural Language Processing
5. **nlp/** - NLP tasks and implementations

## Key Concepts to Master
- Tensors and computational graphs
- Backpropagation and gradient descent
- Activation functions (ReLU, Sigmoid, Tanh)
- Loss functions and optimizers
- Regularization techniques (dropout, batch normalization)
- Training loops and model checkpointing
- Transfer learning

## Common Architectures
- Feedforward neural networks
- Convolutional Neural Networks (CNNs)
- Recurrent Neural Networks (RNNs)
- Long Short-Term Memory (LSTM)
- Transformers and attention mechanisms
