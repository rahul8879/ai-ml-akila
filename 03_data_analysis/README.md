# Module 3: Data Analysis

## Overview
This module teaches exploratory data analysis (EDA) and how to extract insights from real-world datasets.

## Prerequisites
- Module 1: Python Fundamentals (Pandas, NumPy, Matplotlib)
- Module 2: Mathematics (Statistics basics)

## Learning Objectives
By the end of this module, you will be able to:
- Perform comprehensive exploratory data analysis
- Clean and preprocess messy data
- Visualize data patterns and relationships
- Extract actionable insights from datasets
- Handle missing data and outliers

## Study Order
1. **01_eda.ipynb** - Fundamentals of exploratory data analysis
2. **02_tata_retail.ipynb** - Real-world retail data analysis case study

## Key Skills to Practice
- Data cleaning and preprocessing
- Univariate and multivariate analysis
- Statistical summaries and visualizations
- Feature engineering basics
- Identifying patterns and anomalies

## Datasets
Use datasets from the `datasets/` folder for additional practice:
- `Online Retail Data Set.xlsx` - E-commerce transaction data

## Next Module
After mastering data analysis, you're ready for **Module 4: Machine Learning** to build predictive models.
