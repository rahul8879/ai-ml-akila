# Module 1: Python Fundamentals

## Overview
This module covers essential Python programming concepts needed for data science and machine learning.

## Prerequisites
- Basic understanding of programming concepts
- Python 3.x installed on your system

## Learning Objectives
By the end of this module, you will be able to:
- Write basic Python scripts and understand Python syntax
- Work with Python data structures (lists, dictionaries, tuples, sets)
- Use NumPy for numerical computing
- Manipulate and analyze data with Pandas
- Create visualizations using Matplotlib

## Study Order
1. **01_variable_keyword.ipynb** - Variables, data types, and keywords
2. **01_basic_python.py** - Basic Python syntax and control flow
3. **Data_structures/** - Lists, dictionaries, tuples, sets
4. **Functions/** - Function definitions and usage
5. **03_numpy.ipynb** - NumPy arrays and operations
6. **02_pandas.ipynb** - Data manipulation with Pandas
7. **matplotlib/** - Data visualization basics

## Practice Datasets
- `simple_data.*` - Simple datasets in various formats for practice
- `Reviews.csv` - Text data for analysis
- `car_price_dataset_medium.csv` - Numerical data for exploration

Once comfortable with Python fundamentals, proceed to **Module 2: Mathematics** for the mathematical foundations of ML.
