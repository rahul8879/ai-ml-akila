# Module 6: Generative AI

## Overview
This module covers large language models (LLMs), generative AI, and frameworks like LangChain.

## Prerequisites
- Module 5: Deep Learning (especially transformers and attention)
- Module 4: Machine Learning
- Strong Python programming skills

## Learning Objectives
By the end of this module, you will be able to:
- Understand the architecture of large language models
- Work with LLM APIs and frameworks
- Build applications using LangChain
- Implement prompt engineering techniques
- Create retrieval-augmented generation (RAG) systems
- Fine-tune and deploy LLM applications

## Key Concepts to Master
- Transformer architecture and attention mechanisms
- Pre-training vs fine-tuning
- Prompt engineering and few-shot learning
- Embeddings and vector databases
- Retrieval-Augmented Generation (RAG)
- LangChain components (chains, agents, tools)
- Ethical considerations and bias in LLMs

## Popular Frameworks & Tools
- LangChain - LLM application framework
- OpenAI API / Anthropic Claude API
- Hugging Face Transformers
- Vector databases (Pinecone, Chroma, FAISS)
